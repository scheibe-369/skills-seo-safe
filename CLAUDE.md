# Skills SEO Safe para Claude Code

Leia e siga `AGENTS.md` deste repositório para as regras compartilhadas.

Antes de criar, alterar de forma relevante ou finalizar um site, página pública ou landing page, leia `skills/site-seo-release/SKILL.md`. Use a mesma fonte canônica empregada pelo Codex. Execute o modo construção, incremental ou revisão final conforme a tarefa e mantenha `SEO-SPEC.md`, `tasks/site-release.md` e `tasks/site-release.json`.

Quando instalada em `.claude/skills/site-seo-release/`, a skill também pode ser chamada por `/site-seo-release`. Neste repositório de desenvolvimento, o caminho explícito permite ler a skill mesmo sem instalação no catálogo.
